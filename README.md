# 어른뭉방구 카드팩 뽑기 이벤트

경북 포항 종합 문구점 어른뭉방구의 매장 마케팅을 위한 모바일 우선 카드팩 뽑기 웹 이벤트입니다. 카드팩을 개봉하고, 경품 후보 카드 5장을 확인한 뒤 원하는 1장을 선택하는 경험을 제공합니다.

## 프로젝트 상태

1차 목표는 목업 데이터를 사용하는 카드 뽑기 연출과 전체 사용자 흐름을 완성하는 것입니다. 현재 M1(인트로 → 3D 카드팩 등장 → 기울여 보기)까지 구현되어 있으며, 진행 상황은 [PROGRESS.md](PROGRESS.md)에 기록합니다.

## 사용자 흐름

1. 인트로에서 터치해 이벤트를 시작합니다.
2. 카드팩을 살펴보고 정해진 절취선을 드래그해 개봉합니다.
3. 카드 5장을 한 장씩 넘기며 확인합니다.
4. 요약 화면에서 원하는 카드 1장을 선택합니다.
5. 획득 경품과 교환 조건이 담긴 결과 화면을 확인합니다.

1차에서는 추첨 결과와 경품을 목업 데이터로 제공합니다. 경품 교환은 결과 화면에서 안내하며, 방문 기한은 기획 명세 기준 14일입니다.

## 기술 방향

- Vite와 TypeScript를 사용하는 정적 웹 앱
- 실시간 WebGL 렌더링을 위한 Three.js
- 셰이더 기반 카드팩 절취, 포일 반사와 홀로 효과
- 터치와 마우스를 함께 지원하는 Pointer Events 입력
- 모바일 웹 우선 설계와 데스크톱 브라우저 지원

상세 구현 요구사항과 검수 기준은 [PACK_OPENING_SPEC.md](PACK_OPENING_SPEC.md)를 참고하세요.

## 디자인 자료

- `logo.svg`: 프로젝트 로고
- `logo-mono.svg`: 단색 로고
- `logo.png`: 로고 원본 이미지
- `design/logo-overlay-check.png`: 로고 확인용 이미지

## 진행 단계

- **1차:** 팩과 카드 연출, 개봉·스와이프·선택·결과까지 전체 흐름 구현
- **2차:** 승인 후 경품 추첨 API, 1인 1회 제한, 쿠폰 처리와 어드민 구현
- **3차:** 사운드, 기기별 최적화, QA와 배포

## 실행 및 빌드

Node.js 22 기준입니다.

```bash
npm install
npm run dev        # 개발 서버 (같은 Wi-Fi의 휴대폰에서도 접속 가능하도록 --host)
npm run build      # 타입 체크 + 정적 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
npm run typecheck  # 타입 체크만
```

- 앱: `http://localhost:5173/`
- 2D 디자인 시안: `http://localhost:5173/design/` (개발 서버에서 같이 열림)

## 배포

`main`에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해 GitHub Pages로 배포합니다.

- 주소: https://jeondowon.github.io/moonbangoo/
- 폰의 기울기 센서는 HTTPS에서만 동작하므로, 자이로 확인은 로컬 개발 서버(http)가 아니라 배포 주소에서 합니다.
- 하위 경로(`/moonbangoo/`)에서 서비스되므로 `vite.config.ts`에서 빌드 시 `base`를 맞춰 둡니다.

## 주요 결정과 주의사항

- 이벤트는 포켓몬 카드게임의 개봉 경험에서 상호작용과 분위기만 참고합니다.
- 포켓몬 캐릭터, 공식 로고, 카드 디자인 원본과 고유 디자인 요소는 사용하거나 복제하지 않습니다.
- 5장의 후보를 모두 확인한 뒤 사용자가 원하는 1장을 직접 선택합니다.
- 결과는 연출 시작 전에 확정하며, 연출은 결과를 보여주는 역할을 합니다.
- 2차의 서버 추첨, 쿠폰 발급·교환, 개인정보 수집 방식은 별도 결정이 필요합니다.
