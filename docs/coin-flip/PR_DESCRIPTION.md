# 코인 뒷면 PREEM 로고 적용 및 1억 광년 상한 연출 추가

코인 플립의 임시 별 도안을 PREEM patisserie 로고로 교체하고, 끝없이 올라가던 고도에 1억 광년 상한을 추가합니다. 뒷면 로고에는 앞면과 같은 샴페인 골드·양각 재질을 적용합니다.

상한에 가까워지면 반투명한 손이 나타나 코인을 아래로 튕깁니다. 딱밤을 맞아 낙하하기 시작하면 다음 던지기까지 스와이프에 의한 상승·회전·효과음·진동을 차단합니다. 최고기록 저장·표시와 별도 접촉 알림을 제거합니다. 접촉 프레임에는 거리 칸에 `1억 광년`을 표시하고 다음 프레임부터 낙하에 따라 갱신합니다.

## 변경 범위

- 투명 PREEM 도안과 기존 코인 재질 생성 연결
- 상한 접근 감속, 접촉 시 하향 반동·추가 회전 및 다음 던지기까지 입력 차단
- 준비·접촉·후속 자세의 손 아틀라스, 섬광·파문·입자와 카메라 구도
- 500m 유효 조건, 기존 앞면·바닥 결과 결정 알고리즘 유지
- 500m 미만이면 첫 바닥 충돌 시점에 코인 페이드아웃·대기 코인 페이드인을 동시에 시작하고 0.6초 내 복귀 및 재시도 안내

## 검증

- `npm test`: 78개 통과. `npm run build`: 타입 검사·빌드 성공(기존 청크 크기 경고).
- 기존 손 연출의 로컬 브라우저 검증 이력은 LOCAL_REVIEW.md를 참고한다. 최고기록 제거·거리 단일화 이후 브라우저 화면은 아직 재검증하지 않았다.
- 500m 미만 교차 페이드·복귀는 자동 테스트로 검증했으며 브라우저 시각 확인은 아직 수행하지 않았다.
- 실물 iOS/Android 터치·음향·햅틱과 장시간 기기 성능은 추가 확인이 필요하다.
