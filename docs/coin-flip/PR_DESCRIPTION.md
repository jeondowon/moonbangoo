# 코인 뒷면 PREEM 로고 적용 및 1억 광년 상한 연출 추가

코인 플립의 임시 별 도안을 PREEM patisserie 로고로 교체하고, 끝없이 올라가던 고도에 1억 광년 상한을 추가합니다. 뒷면 로고에는 앞면과 같은 샴페인 골드·양각 재질을 적용합니다.

상한에 가까워지면 반투명한 손이 나타나 코인을 아래로 튕깁니다. 딱밤을 맞아 낙하하기 시작하면 다음 던지기까지 스와이프에 의한 상승·회전·효과음·진동을 차단합니다. 접촉 안내에는 `1억 광년`만 강조해 표시합니다.

## 변경 범위

- 투명 PREEM 도안과 기존 코인 재질 생성 연결
- 상한 접근 감속, 접촉 시 하향 반동·추가 회전 및 짧은 양력 회복 대기
- 준비·접촉·후속 자세의 손 아틀라스, 섬광·파문·입자와 카메라 구도
- 500m 유효 조건, 기존 앞면·저장 키·바닥 결과 결정 알고리즘 유지

## 검증

- `npm test`: 76개 통과
- `npm run build`: 타입 검사·빌드 성공
- 같은 비행의 첫 접촉 → 낙하 → 재상승 → 두 번째 접촉을 240/60/20Hz에서 검사
- 로컬 Chrome 390×844에서 실제 마우스 Pointer Events로 동일 흐름과 착지·결과·최고 기록 저장 확인. 두 접촉의 손 텍스처 동일, 바닥 충돌 전 동일 비행
- 데스크톱·모바일 크기에서 접촉 알림 `1억 광년`만 강조되는지 확인

실물 iOS/Android 터치·음향·햅틱과 장시간 기기 성능은 추가 확인이 필요합니다. 기존에 저장한 상한 초과 최고 기록은 보존합니다. 상한 구간의 움직임은 의도적으로 변경됩니다.
